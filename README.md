## 产品介绍

北极熊企微框架 Pro 是一款面向 Windows 企业微信客户端的自动化工具。

软件通过本地 HTTP API 提供企业微信能力，无需申请企业微信开放平台接口，可用于机器人、智能客服、群运营、消息通知及业务系统集成。

适合以下场景：

| 场景 | 说明 |
|---|---|
| 🤖 AI 智能客服 | 接收企微消息，对接 AI 模型后自动回复 |
| 📢 消息通知 | 向客户、群聊发送文本、图片、文件等消息 |
| 👥 社群运营 | 创建群聊、邀请成员、修改群名和群公告 |
| 👤 客户管理 | 查询好友、处理好友申请、修改客户资料 |
| 🏷️ 标签管理 | 查询、添加、修改客户标签 |
| 🔗 系统对接 | 对接 CRM、工单、监控、ERP 等业务系统 |

## 核心功能

### 消息能力

- 接收企业微信聊天消息
- 发送文本、图片、文件、视频和语音
- 发送小程序、名片、位置、卡片链接
- 群聊中发送消息并 @ 指定成员
- 支持撤回消息识别
- 支持消息回调推送
- 支持 AES-256-GCM 加密回调

### 联系人与好友

- 获取外部联系人列表
- 获取企业内部好友列表
- 查询好友详细信息
- 同意好友申请
- 添加和删除好友
- 设置好友备注、描述、公司和手机号

### 群聊管理

- 创建内部群和外部群
- 获取群聊及群成员列表
- 邀请或移除群成员
- 修改群名称和群公告
- 添加或删除群管理员
- 转让群主、退出或解散群聊
- 获取群二维码和群信息
- 管理群欢迎语

### 标签管理

- 获取标签组和标签列表
- 查询指定用户所属标签
- 添加、修改和删除标签
- 给好友添加或移除标签
- 获取标签下的联系人

### 框架管理

- 多个企业微信实例管理
- 企业微信 v4/v5 版本选择
- 登录状态和授权状态检查
- 运行日志查看与保存
- 自动更新
- 崩溃检测与自动恢复
- 最小化到系统托盘

## 快速开始

### 第一步：下载安装包

前往 [Releases](https://github.com/xing653245/WeChat-Work-Hook/releases/latest) 下载最新版 EXE 安装包。

运行安装程序并按照提示完成安装。

> 请仅从本仓库 Releases 页面下载安装包，避免使用来源不明的文件。

### 第二步：选择企微版本

首次启动软件时，根据电脑上安装的企业微信版本选择：

- 企业微信 v4
- 企业微信 v5

版本选择错误会导致注入失败。

### 第三步：添加企业微信

打开软件，进入“企微管理”页面：

1. 在表格空白处点击鼠标右键
2. 选择“添加企微”
3. 等待企业微信启动
4. 完成登录
5. 确认账号出现在企微管理列表中

### 第四步：刷新授权

在“企微管理”列表中右键对应账号，选择“刷新授权”。

授权成功后会显示：

- 企微昵称
- 企微 ID
- HTTP 端口
- 授权到期时间
- 卡密信息

## 端口说明

接口调用中有两个不同的端口，请不要混用。

| 端口 | 用途 | 在哪里查看 |
|---|---|---|
| 框架监听端口 | 写在请求地址中 | 软件“设置”页面 |
| 企微 HTTP 端口 | 写在 JSON 的 `port` 字段中 | 软件“企微管理”页面 |

例如：

- 框架监听端口：`8868`
- 企微管理中显示的 HTTP 端口：`6915`

发送请求时应写成：

```http
POST http://127.0.0.1:8868/api/message/text
Content-Type: application/json
```

```json
{
  "port": 6915,
  "user_id": "接收者的企微ID或群ID",
  "msg": "你好，这是一条测试消息"
}
```

> 请求体里的 `port` 必须与“企微管理”界面显示的 HTTP 端口一致。

## 常见问题

<details>
<summary><strong>已经授权，接口仍然提示端口找不到怎么办？</strong></summary>

打开软件的“企微管理”页面，查看对应账号的 HTTP 端口。

检查接口请求 JSON 中的 `port` 是否与这个端口一致，不一致时修改为企微管理中显示的端口。

</details>

<details>
<summary><strong>购买或续费后为什么还显示未授权？</strong></summary>

在“企微管理”页面右键对应账号，选择“刷新授权”。

如果仍然无效，请检查网络、VPN 或代理设置。

</details>

<details>
<summary><strong>添加企微后一直无法登录怎么办？</strong></summary>

请确认：

1. 企业微信版本与软件选择的 v4/v5 版本一致
2. 企业微信没有自动升级
3. 企微进程没有残留
4. 重新退出企业微信和框架后再次添加

</details>

<details>
<summary><strong>为什么安全软件会提示风险？</strong></summary>

本软件需要使用 Hook 和进程注入技术连接企业微信客户端，部分安全软件可能产生提示。

请仅从本仓库 Releases 页面下载安装包。

</details>

<details>
<summary><strong>支持个人微信吗？</strong></summary>

不支持。本软件仅面向企业微信 PC 客户端。

</details>
