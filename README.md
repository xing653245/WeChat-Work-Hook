## 产品介绍

北极熊企微框架 Pro 运行在安装了配套企业微信客户端的 Windows 环境中，使用自研 **BJX.dll** 提供客户端接口能力，并通过可视化桌面工具管理企微实例、接口端口、消息回调和运行日志。

开发者可以使用 Python、Node.js、Java、Go、PHP、C# 等语言调用接口，将企微消息与自己的业务程序连接起来。

支持与个人微信用户、企业微信用户进行消息交互，支持内部群和外部群相关操作。联系人、群聊和管理操作的实际可用范围，以登录账号的关系、权限及接口返回为准。

### 桌面管理

- 查看企微账号、昵称、HTTP 端口和授权状态。
- 自动检测已接入实例，支持手动重新检测。
- 按账号独立配置回调地址、超时时间、重试次数和消息加密。
- 保存和恢复账号对应的回调设置。
- 查看运行日志、打开日志目录、合并日志和导出故障报告。
- 检查软件更新，最小化到系统托盘。

| 项目 | 说明 |

| 运行系统 | Windows 10 / Windows 11，64 位系统 |

企业微信客户端需要与框架适配版本匹配。升级客户端前，请先确认对应版本已获得支持。

框架及企微客户端运行在 Windows 上，其他系统中的业务程序可通过受控网络对接实例接口。

## 快速开始

### 1. 下载并安装

前往 [GitHub Releases](https://github.com/xing653245/BJX-WeChat-Work-Hook/releases/latest) 下载框架安装包，并准备配套版本的企业微信客户端。

### 2. 配置客户端路径

打开框架，在“设置”中选择配套企业微信客户端路径并保存。

### 3. 启动企业微信

进入“企微管理”，通过“添加企微”启动客户端并完成登录。支持使用自动分配的端口，也可以按需要指定端口。

### 4. 确认账号与授权

在企微管理列表中确认账号、HTTP 端口及授权状态。获取或续期授权后，右键对应账号执行“刷新授权”。

### 5. 调用接口

业务程序直接请求目标企微实例的 HTTP 端口。不同实例应使用各自显示的端口。

### 6. 设置回调

在“连接、回调与加密”中选中目标企微，填写业务程序的回调接收地址，开启原生回调，然后点击“更新当前企微”。

接口地址用于业务程序调用企微；回调地址用于企微向业务程序推送事件，两者用途不同。

## 接口调用示例

下面以实例端口 `8989` 为例。请替换为“企微管理”中实际显示的 HTTP 端口。

### 查询登录状态

在 **Windows PowerShell** 中执行：

```powershell
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:8989/api" `
  -ContentType "application/json" `
  -Body '{"type":1000}' | ConvertTo-Json -Depth 10
```

### 查询当前账号信息

请求地址：`POST http://127.0.0.1:8989/api`

```json
{
  "type": 1002
}
```

### 发送文本消息

请求地址：`POST http://127.0.0.1:8989/api`

```json
{
  "type": 3000,
  "user_id": "替换为目标联系人ID或群ID",
  "msg": "你好，这是一条测试消息。"
}
```

联系人 ID、群 ID 和消息 ID 请按文档使用字符串，避免长整数精度丢失。发送前请确认目标存在、账号关系及参数有效。

接口调用后需要检查返回中的 `errno` 和错误说明。HTTP 请求成功不等于业务执行成功；接口确认接收也不等于接收方已经阅读。

## 消息回调

框架支持将企微事件推送到指定接收地址。业务程序可依据消息类型、会话 ID、发送者及消息 ID 进行处理。

群聊文本回调示意：

```json
{
  "type": 100,
  "msg_type": 2,
  "self_user_id": "当前登录企微ID",
  "user_id": "R:群ID",
  "sender": "群成员ID",
  "msg_id": "消息ID",
  "content": "收到的消息内容",
  "is_self_msg": 0,
  "at_list": []
}
```

- `self_user_id`：接收该回调的登录企微账号。
- `user_id`：会话目标，群聊时为群 ID。
- `sender`：群消息的实际发送者。
- `msg_id`：消息标识，可用于业务程序去重。
- `is_self_msg`：是否为登录账号自己发送的消息。
- `at_list`：消息中被 @ 的成员 ID 列表。

以上为字段示意，完整回调结构及加密配置请查看接口文档。

## 常见问题

### 接口连接失败怎么办？

确认企微由框架启动且已接入，核对企微管理中显示的实际 HTTP 端口，并先在同一台 Windows 机器上测试登录状态接口。

`127.0.0.1` 代表执行请求的本机；从其他机器访问时，不能用它代替企微所在机器的地址。

### 能直接运行个人微信吗？

本框架适配企业微信客户端。登录企业微信后，可与该账号能够联系的个人微信用户交互。

### 为什么收不到回调？

确认选择了正确账号、已开启回调并点击“更新当前企微”，同时检查接收程序是否运行，以及企微所在机器能否访问该地址。

### 可以直接升级到任意版本的企业微信吗？

请使用框架明确支持的配套版本，其他版本需等待适配与验证。
